# 📊 GlobalMart Sales Dashboard — Excel Pivot Table Analysis

> An interactive sales performance dashboard built entirely in Excel using Pivot Tables, Pivot Charts, and Slicers — analyzing 15,150+ simulated e-commerce transactions across **Sri Lanka, UAE, and Oman**.
