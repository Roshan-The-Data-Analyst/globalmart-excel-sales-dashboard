# GlobalMart Sales Dashboard

An interactive Excel sales dashboard built with PivotTables, PivotCharts, slicers, and data-cleaning workflows. The project explores simulated e-commerce transactions across Sri Lanka, the UAE, and Oman.

![GlobalMart dashboard preview](https://github.com/user-attachments/assets/ad746762-618c-4040-b21b-f78010d1cab9)

## Project overview

The goal is to turn transaction-level sales data into a clear, decision-ready view of business performance for regional managers and other stakeholders.

| Item | Details |
|---|---|
| Project type | Excel data analysis and dashboard |
| Dataset | Simulated e-commerce transactions |
| Records | 15,150+ transactions |
| Regions | Sri Lanka, UAE, Oman |
| Main tools | Microsoft Excel, PivotTables, PivotCharts, slicers, Power Query |

## Dashboard capabilities

- Summarizes sales by region, product category, and time period.
- Uses PivotCharts to communicate sales patterns and comparisons.
- Uses slicers for interactive filtering.
- Presents key performance information in an executive-style dashboard.

## Analysis workflow

1. Inspect the source transaction data and understand the fields.
2. Clean and standardize dates, values, and categories.
3. Create calculated fields where required, such as revenue.
4. Build PivotTables to summarize the measures and dimensions.
5. Create PivotCharts and add slicers for interactive exploration.
6. Validate totals and document insights supported by the data.
